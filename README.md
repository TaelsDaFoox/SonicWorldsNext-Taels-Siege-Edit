An expansion of the Sonic Worlds Next framework (https://github.com/Techokami/SonicWorldsNext) focused on adding more features to complement a more fast-paced gameplay style.

Created using Godot, paint.net, blender, and apicula (for model ripping).

check out the itch.io page for a list of changes and to try it yourself! https://taelsdafoox.itch.io/taerusu-worlds-next
